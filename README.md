# KN-RAI-Stanowisko-MPS-403-1
Repozytorium projektu w ramach działalności Koła Naukowego Robotyka Automatyka Informatyka (RAI) na Politechnice Poznańskiej. Rozwój stanowiska dydaktycznego Festo MPS 403-1 zgodnie z ideą Przemysłu 4.0, obejmujący rozbudowę systemu MES, opracowanie wizualizacji HMI/SCADA oraz możliwość stworzenia cyfrowego bliźniaka (Digital Twin).
